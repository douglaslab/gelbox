# Historical plans and specifications

As of 2026-10-09, [../ROADMAP.md](../ROADMAP.md) is the forward roadmap, [../STATUS.md](../STATUS.md) is current implementation status, and [../PORT-AUDIT.md](../PORT-AUDIT.md) is the seed native-parity inventory.

The M1–M27 plans/specifications in this directory document the earlier implementation effort. Preserve them for rationale and code references, but do not execute their remaining checkboxes without reconciling them with the new roadmap. In particular, the old Rust trajectory, UI redesign assumptions, invented shader/bloom work, and image-to-sample milestone are not current requirements.

The current goal is strict native behavior and visual parity first, web first. New per-increment implementation plans may live here once their native reference cases are established; they must identify the corresponding P0–P5 gate and distinguish proposed behavior from implemented and verified behavior.
